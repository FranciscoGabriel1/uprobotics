# UpRobotics Web

## Requisitos

- Node.js 22.x
- Yarn 1.22+

## Rodando localmente

```bash
yarn install
yarn dev
```

## Scripts

- `yarn dev`: inicia o ambiente de desenvolvimento
- `yarn build`: gera a build de producao
- `yarn start`: inicia a build gerada
- `yarn lint`: executa o lint do projeto
